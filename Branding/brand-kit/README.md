# IP Animations — Brand Kit v1

- **IP Animations Brand Kit.dc.html** — the guidelines (logo, animated logo, icons, colour, type, rules, applications).
- **IP Animations Logo Animated.dc.html** — the animated logo; controls for variant (wave/switch), theme, size, transparent.
- **logos/** — PNG @2x and SVG for each colourway. SVGs link the Grandstander web font; outline the text in a vector tool before print.
- **icons/** — app icon tiles (SVG 1024 + PNG), favicon.svg, bare marks.
- **colours.css / colours.json** — tokens.

Ten rules, short: one Grape thing per screen; one or two Sunbeam things; text is neutral; small type, big space; three rows; the dot ends headlines; highlights are flat; soft corners, not pills; the logo is the only rainbow; motion is for the logo and the work.
